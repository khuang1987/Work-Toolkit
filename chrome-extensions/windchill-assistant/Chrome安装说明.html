Windchill Work Assistant

Chrome 本地安装说明 · v1.5.2

本安装包用于公司内部测试。安装不需要 Google 账号，但需要在 Chrome 中开启一次“开发者模式”。

一、解压安装包

  1. 右键 ZIP 文件，选择“全部解压缩”。
  2. 将解压后的文件夹保存到不会被删除的位置，例如“文档\Windchill Work Assistant”。
  3. 确认该文件夹内可以看到 manifest.json 文件。

二、加载到 Chrome

  1. 打开 Chrome，在地址栏输入 chrome://extensions 并回车。
  2. 打开右上角的“开发者模式”。
  3. 点击“加载已解压的扩展程序”。
  4. 选择刚才解压、且包含 manifest.json 的文件夹，然后点击“选择文件夹”。
  5. 看到“Windchill Work Assistant”卡片后，说明安装完成。

三、开始使用

  1. 打开或刷新公司 Windchill 页面。
  2. 右下角出现“Windchill 助手”输入框后即可使用。
  3. 第一次使用登录填充时，点击 Chrome 工具栏的扩展图标，填写并保存账号密码。
  4. 如需使用审批摘要，点击助手顶部的“审批摘要”。

四、固定助手图标

  1. 点击 Chrome 工具栏右侧的拼图图标。
  2. 找到“Windchill Work Assistant”。
  3. 点击右侧的图钉，将它固定到工具栏。

常见问题

  • 找不到“加载已解压的扩展程序”：请确认“开发者模式”已经打开。
  • 提示无法安装：请使用“加载已解压的扩展程序”，不要双击 ZIP 文件。
  • 助手没有出现：确认当前网址是公司 Windchill，并刷新页面。
  • 更新版本：下载新版并解压到新文件夹，在扩展页面移除旧版本后重新加载新文件夹。
  • 安全提示：不要删除已加载的文件夹，也不要修改其中的文件名。

本扩展只使用当前 Windchill 页面权限，不提供批量下载，也不会把账号密码发送给项目维护者。
