# Windchill Work Assistant

独立的 Windchill Chrome 扩展，保留 Windchill 自动填充、Basic Auth、原生高级搜索和审批摘要功能。

## 功能

- Windchill 登录表单每页只自动填写一次：等页面稳定后填入并复核（被页面清掉会重填，最多 10 次），再自动点击「完成任务 / Complete Task」；只匹配可见输入框，页面内切换任务会重新填充。可通过扩展弹窗保存账号密码。
- 支持 Windchill Basic Auth 自动应答（同一请求只提交一次凭据，密码错误时不会反复重试导致账号锁定）。
- Windchill 页面右下角直接显示紧凑查询框，不再需要先点击助手图标。
- 输入停止约 0.25 秒后更新数量汇总；点击检索按钮或按 Enter 后，才会填写并提交 Windchill 自带的高级搜索，避免输入过程只提交第一个字符。
- 输入框下方提供三个可多选的快捷筛选框：图纸按名称包含关键词且主文件为 PDF，工程文件按 MG/PS 前缀匹配，质量文件按 PII 前缀匹配；下方另有 PDF、DWG、Word、Excel、PPT、压缩包格式多选。
- 切换业务标签或文件格式后会合并为一次新的查询，汇总完成后再更新 Windchill 结果；不需要重新手动点击检索，也不会在加载过程中反复跳动。
- 原生结果会按编号回配汇总数据，避免 Windchill 全局搜索框、版本列或名称列被误识别为结果编号。
- 图纸筛选以“名称包含关键词、主文件为 PDF、编号/名称不带业务前缀”为主规则；工程/质量分类同时检查编号和名称中的 MG/PS、PII 前缀。Windchill 结果行的图纸/CAD 图标只作增强证据，图标异步加载时会继续复核，避免非 PDF 混入或结果反复变化。
- 分类接口采用 12 秒超时、旧请求取消和部分成功策略；单个接口短暂异常时保留已取得结果并提示结果可能不完整，避免整次结果被清空。
- 原生结果区采用延迟绑定和局部监听：结果表出现后再写入“在表格中搜索”，只监听结果区的图标变化，减少 Windchill 长列表滚动时的页面负担。
- 智能查询浮层只显示“共 xx 条”的数量汇总，不在浮层里重复展示结果卡片；审批摘要单独显示待审批数量和少量分组明细。
- 审批摘要状态下隐藏查询输入和筛选控件，显示待审批信息汇总、按活动分组的简要明细，以及当前审批页的主题、编号、版本、流程、负责人、优先级和截止时间；审批对象标题和任务均可点击跳转。
- 登录填充改为“自动填充”勾选项：勾选时页面自动填写，取消勾选后不自动填写、由用户手动输入。
- 打开 Windchill WorkItem 审批详情页后，会在原生审批表单上方插入“审批重点”卡片，避免审批页只显示操作按钮而看不到主题和任务背景。
- 审批数据以 Windchill 首页任务表为准：首页读取并缓存完整任务信息；进入任务详情页后沿用首页数据，不重复刷新审批列表，详情页隐藏“刷新汇总”。
- 审批详情页顶部采用左右布局：左侧保留 Windchill 原生审批、账号和密码输入，右侧显示助手提供的主题、编号、版本、项目/上下文、流程和变更说明。
- 悬浮框可拖动，位置会保存在本地；点击右上角“−”可收起为 Windchill 单图标，再点击图标恢复。
- 保留可选的每日打开 Windchill 首页和右键停止自动填充。

已移除 PDF 图纸批量下载及相关下载权限。

## 1.5.2 更新

- 检索结果直接列在面板内，按相关度排序（编号完全一致优先），点击条目打开；沿 OData nextLink 翻页取全（Windchill 默认每页仅 25 条），首批渐进显示，最多 100 条。
- 质量/工程分类改为服务端按编号前缀（PII / MG、PS）过滤，并显示系统匹配总数。
- 登录填充后自动点击「完成任务 / Complete Task」；可选试运行开关 `windchillDryRun`（只提示不点击）。
- 新图标与黑底细线风格的弹窗；右键菜单去除 emoji。

## 分发

当前版本已准备 Chrome Web Store 上传包：`../windchill-assistant-share/windchill-work-assistant-1.5.2.zip`。压缩包内含 `Chrome安装说明.html`，员工解压后可直接打开查看安装步骤。建议使用 Chrome Web Store 的“未列出”可见性，发布名称使用 `Windchill Work Assistant`，再把商店链接发给指定同事。普通同事不需要 Google 账号，但发布者需要使用自己的 Google 账号登录 Chrome Web Store 开发者后台完成上传和审核。

同事版安装说明见：`../windchill-assistant-share/同事安装说明.html`；发布文案和隐私说明草稿见：`../windchill-assistant-share/ChromeWebStore发布信息.md`。扩展本身必须保留目标 Windchill 站点的访问权限，Chrome 的权限提示可能显示该站点地址；商店名称、说明和安装页不包含公司名称。

## 安装

1. 打开 `chrome://extensions/` 并启用「开发者模式」。
2. 点击「加载已解压的扩展程序」。
3. 选择当前目录 `chrome-extensions/windchill-assistant`。
4. 点击扩展图标，保存 Windchill 用户名和密码。

升级代码后，请在扩展管理页点击「重新加载」，再刷新 Windchill 页面。

原 `password-autofill` 扩展已不再注入 Windchill 页面；EHR、Cornerstone、Planner、Workday 等功能继续由原扩展负责。
