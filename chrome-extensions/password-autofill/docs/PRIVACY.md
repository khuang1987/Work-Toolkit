# Work Assistant Toolkit 隐私权政策 / Privacy Policy

更新日期 / Updated: 2026-05

## 中文

Work Assistant Toolkit（以下称"本扩展"）是在用户自己的浏览器中运行的辅助工具。

1. **不收集、不出售数据**：开发者不运营任何服务器，不收集、不上传、不出售、不共享任何用户数据。
2. **本机存储**：设置、规则库、操作记录、AI 对话记录均保存在浏览器本地存储（chrome.storage.local）中，可在插件后台随时导出或清空；卸载扩展即全部删除。
3. **可选的 AI 功能**：默认关闭。仅当用户自行填写 AI 接口地址与密钥，并主动点击相关按钮时，才会把用户选中的页面文本发送到用户自己配置的服务。密钥在本机加密保存，不会发送给开发者。
4. **页面内容**：本扩展仅在用户指定的文档管理与任务协作网站上运行，读取页面内容只用于在本机完成检索、下载与填写，不用于广告、画像或与功能无关的目的。
5. **下载**：下载的文件保存到用户浏览器的下载目录。
6. **联系方式**：khuang1987@users.noreply.github.com，或在本仓库提交 Issue。

## English

Work Assistant Toolkit runs entirely inside the user's browser.

1. **No collection, no sale**: the developer operates no servers and does not collect, transmit, sell or share any user data.
2. **Local storage only**: settings, rules, activity logs and AI conversation logs are stored in `chrome.storage.local`, can be exported or cleared from the extension's options page, and are removed when the extension is uninstalled.
3. **Optional AI features**: disabled by default. Only when the user supplies their own AI endpoint and API key and explicitly triggers an action is the selected page text sent to that user-configured service. The key is stored encrypted locally and is never sent to the developer.
4. **Page content**: the extension runs only on the document-management and task-collaboration sites the user uses, and reads page content solely to search, download and fill forms locally.
5. **Downloads** are saved to the browser's download folder.
6. **Contact**: open an Issue in this repository.
