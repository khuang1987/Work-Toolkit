# Medtronic Smart Assistant

Medtronic Smart Assistant 是一个Chrome浏览器扩展，旨在提高Medtronic员工日常工作效率。它提供了多个系统的快速访问、自动化填充及定时启动功能。

Windchill 功能（登录自动填充、Basic Auth、原生高级搜索、审批摘要）已同步整合进本综合包（源自 `../windchill-assistant` v1.4.6）。注意：Windchill 凭据在综合包中使用独立存储键 `windchillUsername/windchillPassword`，需在弹窗重新填写；请勿同时启用两个扩展，以免在 Windchill 页面重复注入。

## 功能特点

### 1. 快速访问
- 一键访问Cornerstone学习平台
- 一键访问EHR系统
- 美观的渐变色卡片式界面
- 点击系统名称直接打开网页

### 2. 自动填充功能
- **EHR系统**: 
  - 自动填充账号密码
  - 自动聚焦验证码输入框
  - 需要手动输入动态验证码
  - 不进行登录成功检测
- **安全存储**: 所有密码使用Chrome安全存储机制

### 3. Cornerstone自动化
- 自动点击功能（可选启用，在弹窗 Cornerstone 卡片中开关）
- 页面右下角为默认折叠的助手图标（与 Windchill 一致），点击展开；面板含自动点击、自动过课、跳过视频，面板内「–」收起；运行中图标显示绿点
- 自动完成课程进度
- 可自定义点击次数（1-100次）
- 智能识别按钮状态

### 3.1 Workday 助手
- 页面右下角一个默认折叠的「Workday 助手」图标，展开后分「绩效评估」与「职务申请」两页，共用日志区（原来的两个面板已合并）
- 绩效评估：评分 / 提交 / 谈话，次数可设置
- 职务申请：记住当前值、按起始序号和份数批量新开标签页填写；批量打开的标签页会自动展开面板并切到该页

### 3.2 共享悬浮面板
- `mwa_dock.js` 提供右下角、亮色圆角的可折叠面板（默认折叠为 48px 图标），供 Cornerstone 与 Workday 使用
- 弹窗为亮色 iOS 风格（宽 300px）；扩展图标为 iOS 圆角方形（对勾 + 星光：任务完成 + AI 优化）

### 4. EHR 一键审批 (新)
- **悬浮面板**: 登录 EHR 后,页面右下角是默认折叠的「EHR 助手」图标（与 Cornerstone / Workday / Windchill 同一风格和交互），点击展开后点「一键审批」
- **点击后自动汇总**所有待审批事项(补卡/请假/加班等全部分类),弹出汇总窗口
- **电光蓝高亮**: 请假/加班时长超过 1 天(>24h)的记录以电光蓝标注,方便差异识别
- **默认全选**,可取消勾选异常项,也可全选/全不选/反选
- 确认后逐条审批当前类别的勾选项,每行显示审批中/已完成/失败状态
- 点击底部「🔄 刷新汇总」刷新 EHR 页面并重新拉取最新列表

### 4.0 Windchill 助手浮层
- 每次打开页面默认折叠为右下角 48px 圆角方形图标（与其他页面统一），不遮挡页面；点击展开、`−` 收起，展开/收起为从右下角平滑缩放的形变动画
- 展开后可拖动标题栏临时移动，收起时图标停在面板右下角位置；刷新页面后回到右下角

### 4.1 待办同步到工作工具箱
- `pending_sync.js`（由 `background.js` 引入）每 10 分钟、以及打开 Windchill / EHR 页面后，用当前浏览器登录读取 Windchill `Workflow/WorkItems`（Potential）和 EHR 各流程待审批数量与摘要，以及 Fabriq（`/api/v2/notifications/`）未读通知；Fabriq 需先在浏览器登录一次
- 结果只 POST 到本机 `http://127.0.0.1:47821/pending`，由工作工具箱在悬浮栏显示红色角标；工具箱未运行时静默跳过
- 未登录或会话过期时上报错误，工具箱保留上次数量并提示

### 5. EHR 申请填写助手（已暂停）
> 2026-11-04 起暂不启用：不再显示「申请填写」入口，加班 / 请假 / 补卡表单页也不再出现填写助手浮层（代码保留，`content_ehr_approve.js` 中 `FILL_ASSISTANT_ENABLED = false`）。以下为历史说明。

- 登录 EHR 首页右下角点击「📝 申请填写」,在统一窗口中切换三种申请类型
- 统一窗口左侧为 EHR 原生表单,右侧为填写侧栏,不会遮挡表单内容
- 进入「考勤管理 → 加班申请 → 新增」,「请假管理 → 新增」或「补签管理 → 新增」后显示填写助手
- 默认选择当前登录本人,仍可打开员工选择器改为多人
- 加班支持 `08:00-16:00`、`16:00-24:00`、`24:00-08:00` 三个班次; 设置开始时间和时长自动计算结束时间,时间可手动修改
- 加班侧栏提供白班/中班/夜班、1/2/3 小时快捷按钮; 请假提供 8 小时快捷按钮
- 批量请假使用 `PLQJ01 / PLQJ_02` 表单,第 1-5 行可分别选择员工和请假类型
- 个人批量加班使用 `GRPLJB001`,适合一个人多条加班明细; 批量加班使用 `PLJB06`,适合多人逐行填写; 补卡保持单人
- 请假支持选择请假类型和起止日期时间; 补卡支持选择上班/下班和补卡原因
- 点击「确认填入」只填充表单,不会自动保存或提交; 请核对后手动点击 EHR 原生保存按钮

### 6. 每日定时启动
- 可开启"定时启动"功能
- 自定义启动时间（默认 09:00）
- 每天自动打开 EHR 页面
- 开关式控制，方便启用/禁用

### 7. 紧急控制
- 右键菜单快速访问常用功能
- 一键中止所有正在运行的自动化操作
- 桌面通知确认操作完成

## 安装方法

1. 打开Chrome浏览器，进入扩展程序页面：
   - 在地址栏输入：`chrome://extensions/`
   - 或者点击菜单 -> 更多工具 -> 扩展程序

2. 启用"开发者模式"（右上角开关）

3. 安装扩展：
   - 点击"加载已解压的扩展程序"
   - 选择本插件所在文件夹

## 使用说明

### Fabriq AI 优化

- 在插件弹窗展开 Fabriq 卡片，选择接口类型。OpenAI 兼容地址为 `https://api.gpt.medtronic.com/providers/openai/v1`；Claude 地址为 `https://api.gpt.medtronic.com/providers/anthropic/v1`。不要追加 `/chat/completions` 或 `/messages`。切换公司接口类型时地址会自动调整。
- 填写 Key，点击「刷新模型列表」，从模型输入框的建议列表选择或手动输入准确的模型 ID，然后保存。只显示接口实际返回的文本模型，不把不存在的模型加入列表。公司接口于 2026-11-04 列出 `anthropic.claude-opus-5-5`（Claude Opus 5.5），未列出 Sonnet 5.5；可用性以刷新结果为准。
- Luna 的准确 ID 为 `gpt-5.6-luna`，使用公司 OpenAI 兼容接口，而不是 Anthropic 接口。2026-11-04 已用虚构文本验证其描述优化与三条任务拆分。无需为 Luna 另存 Key；在插件工具栏弹窗（托盘设置）的 Fabriq 卡片中选择接口和模型，保存后下次生成生效。
- 在公司 GPT 的 API 设置页创建专用 Token。只用 GPT 时选择 OpenAI 的 Models 和 Chat completion；使用 Claude 则增加 Anthropic 的 Models 和 Messages 权限，无需文件或流程权限。Key 仅在创建时显示，请直接填入插件，不要写入源码、日志或聊天。Key 使用 `chrome.storage.local` 保存在当前浏览器配置中，不是加密保险库；不同 Chrome 配置文件不会共享设置。
- 公司新版 Providers API 使用 Bearer Token；不要使用将于 2026-11-24 停用的 Classic API 3.0。开发者 Token 最长 90 天，到期后需在插件中更新。
- 在 Fabriq 工单弹窗中，AI 优化按钮是一个**蓝色图标按钮**（无文字，与页面按钮同高同色系），位于 **工单 ID 左侧**；鼠标悬浮显示提示，并随页面语言（`<html lang>`）切换中 / 英文（`AI optimize` / `AI 优化`）；没有工单 ID 的未保存工单退回 Description 标题行右侧。**默认不展开**，只有点击按钮才展开右侧 AI 栏，再点一次收起。Fabriq 自带右侧栏被收起时，点击会先把它展开，收起 AI 栏时再还原到原来的状态；AI 栏覆盖在评论区上方，不改动页面原有结构。页面上没有常驻输入框。
- AI 栏内是一组单项功能：**优化标题**、**优化描述**（按六项模板）、**拆分任务**（补充新任务）、**分配时间**（只为尚无日期的任务建议截止日期，已有日期不会覆盖）；每个只处理对应内容，只发送并对比对应部分。底部是大的 **完整优化**按钮：一次生成标题 + 描述 + 任务并对比。调整方向用可多选的芯片（点击变色，含「一周内完成」「两周内完成」等），需要补充时点「其他…」展开自由输入。生成后弹出前后对比：左侧为原文，右侧为建议；红色删除线表示删除或改写前的内容，绿色表示新增或改写后的内容。不会直接覆盖工单。
- 描述不清楚时可点「问答补充」，或由 AI 在信息严重不足时主动提问（仅在生成描述时）：每轮 1–3 个问题，回答后继续，**最多 5 轮**；也可随时「跳过，直接生成」，不明确的项留空。第 5 轮回答后一定直接生成结果。对比弹窗中的「重新生成」只调整结果，不再提问。
- 对比弹窗可编辑建议标题和描述（高亮同步更新）；新增任务可修改和取消勾选，已有任务不会删除。不满意时可选择调整方向重新生成，上一版用户编辑后的预览会作为上下文。
- 对比弹窗按区块排列，只显示本次功能涉及的区块：「任务标题」「描述」「任务」「任务时间」，每个区块标题右侧是对应的「应用标题」「应用描述」「添加任务」「应用时间」按钮；标题区只有一个可直接编辑的「优化后」框；底部只有「取消」和「全部应用」，右上角为关闭按钮；「调整方向」常显，并按功能给出针对性芯片（如标题：更简短、突出设备 / 工序、突出问题现象等）。任务时间区块列出建议日期（可修改、取消勾选），应用时通过 Fabriq 自带的日期选择器写入，过去的日期会被拒绝。只有点击这些应用按钮才写入（标题最后写入）；取消、关闭或 Esc 不回退此前已经确认应用的部分。已应用的项会禁用重复应用。生成后若工单被切换、关闭，或描述/任务另有改动，会阻止覆盖并提示重新生成。首次应用标题后请核对 Fabriq 的保存状态。
- Fabriq 的任务列表是懒加载的：读取前会先滚动让任务行渲染，避免漏读已有任务而重复拆分。
- 任务按「新建空白行 → 输入 → 失去焦点」保存，不再按 Enter，因此不会额外保存空白任务；已有的空白任务行会被优先填入，其余任务保持不变。
- 页面中不显示模型选择或刷新按钮，模型、接口和 Key 统一在插件工具栏弹窗中配置。每次生成读取已保存的模型；不会因请求失败自动改用其他模型。Claude 使用 Messages 协议，GPT 使用 Chat completions 协议。
- 点击单项优化、完整优化、问答提交或重新生成才发送当前工单的标题、描述、已有任务（排期时还有今天日期和待排期任务）、调整方向、问答内容和上一版预览。展开面板本身不会发送数据。
- 开发调试使用 `dev-chrome.bat`（需要 Node.js 22+）。它使用独立的 `MWA-DevProfile` 和本机 9333 调试端口；已在普通 Chrome 中配置的登录、扩展和 Key 不会自动复制过去。加载或重载扩展后刷新目标页面。
- 回归验证：在本目录执行 `node --test tests\fabriq_ai.test.cjs tests\fabriq_ai_helpers.test.cjs`，覆盖接口适配、六项模板校验和中文差异高亮，不使用真实 Key 或发送网络请求。

#### 六项日常描述模板

1. 发生了什么？
2. 在什么工序，哪台设备，什么时间，哪个批次，谁发现的？
3. 影响是什么？（停机，报废，交付，NCMR，OEE）请在下面描述具体影响。
4. 当前已采取了什么措施？（需要提供正确的数据，图纸或照片）
5. 期望解决什么问题？
6. 升级前是否得到了反馈或回复，是什么？

生成描述必须按上述顺序保留六个标题。不明确或未提供的内容**不写「待确认」等占位语**，该问题下留空，只写已知内容；没有提供的数据、图纸、照片或反馈不能编造为已有证据，已采取措施不能与建议措施混淆。写入 Fabriq 时六个问题以**列表（黑点）**显示，回答是列表项内不带黑点的普通段落；模型返回的【】标记和「待确认」类占位行会在预览前清除。不完整的模板或无效 JSON 不会进入应用流程。

#### 看不到 AI 优化按钮时

- 按钮不在看板首页、Chrome 工具栏或独立侧栏中。先点开一个工单详情，按钮位于工单 ID 左侧（蓝色图标，悬浮提示）；点开后右侧评论区被 AI 面板覆盖，模型选择在插件工具栏弹窗中。
- 页面加载时插件注入 `content_fabriq_ai.js`，通过 MutationObserver 检测工单弹窗；关闭详情后按钮随弹窗移除。只有点击生成才会发送工单内容，只有点击应用才会写入。
- 标题定位优先使用页面的 `data-qa="title"` 或 `.ticket-title` 标识，不依赖英文提示文字，中文标题提示下也会显示按钮。
- 已加载本目录的插件通常无需卸载重装：打开 `chrome://extensions/`，找到 Medtronic Work Assistant，点击重新加载，然后刷新 Fabriq 标签页，再打开工单详情。只刷新 Fabriq 不会让后台脚本自动更新。
- 在扩展详情页核对加载目录是否为本 README 所在目录；如果使用 `C:\Apps\Surfari_Extension` 等复制目录，源码更新不会自动同步过去。先更新对应副本，再重新加载；若当前浏览器尚未安装，才需要「加载已解压的扩展程序」。
- 普通 Chrome 与开发 Chrome（`MWA-DevProfile`）的插件设置彼此独立。看得到按钮但提示未配置 AI 时，在当前浏览器的 Fabriq 卡片配置 Key；不要复制正在运行的 Chrome 数据库或把 Key 写到笔记。

### 快速访问和设置
1. 点击Chrome工具栏中的插件图标打开弹出窗口
2. 直接点击系统名称（如 Cornerstone、EHR）即可快速打开对应网页
3. 点击右侧的 ▼ 图标可展开/收起设置区域
4. 在设置区域中配置账号密码等信息

### 键盘快捷键
- **Ctrl/Cmd + S**: 保存当前展开的设置
- **Enter**: 在输入框中按回车键快速保存

### 右键菜单功能
在Chrome工具栏中右键点击插件图标，可以快速访问以下功能：
- **自动点击开关**：快速启用/禁用Cornerstone自动点击功能
- **自动关闭弹窗开关**：快速启用/禁用弹窗自动关闭功能
- **🛑 中止所有插件指令**：立即停止所有正在运行的自动化操作
  - 停止自动点击
  - 停止登录重试
  - 清理所有运行状态
  - 适用于需要紧急中断插件操作的场景

### 弹出窗口功能
- **一键打开**：点击系统名称直接打开对应网页
- **展开设置**：点击右侧 ▼ 图标展开/收起设置区域
- **美观界面**：渐变色设计，卡片式布局，操作更直观
- **智能交互**：设置区域可展开收起，节省空间

### 系统设置
1. 点击"设置"标签页
2. 根据需要配置各系统：

#### Cornerstone设置
- 设置自动点击次数（1-100次）
- 点击"💾 保存设置"按钮保存设置
- 启用/禁用自动点击功能请使用右键菜单

#### EHR设置
- 输入EHR系统的用户名和密码
- 点击"💾 保存设置"按钮
- 访问 EHR 时自动填充账号密码
- 自动聚焦验证码输入框
- 需要手动输入动态验证码

#### 每日定时
- 开启"每日自动打开页面"开关
- 插件将在每天 09:00 自动为你打开工作页面

## 安全说明

- 所有密码信息均使用Chrome安全存储机制保存
- 账号信息仅在本地保存，不会上传到任何服务器
- 插件仅在指定的Medtronic系统域名下运行

## 常见问题

### 如何在无痕模式(Incognito)下使用？
默认情况下，Chrome 扩展在无痕模式下是禁用的。如需开启：
1. 在浏览器地址栏输入 `chrome://extensions/`
2. 找到本插件，点击 **详细信息 (Details)** 按钮
3. 向下滚动，找到 **在无痕模式下启用 (Allow in Incognito)** 选项
4. 点击开关将其启用即可
