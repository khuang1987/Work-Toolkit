## 3.0.0

- **结构拆分**：1400 行的 `content_fabriq_ai.js` 拆为样式（`fabriq_ai_style.js`）、页面层（`fabriq_page.js`：读写工单的全部 DOM 操作，选择器集中在 `SELECTORS`）、AI 客户端（`fabriq_ai_client.js`）、AI 可靠性层（`fabriq_ai_guard.js`）、操作记录 / 撤销（`fabriq_undo.js`），主文件只保留界面逻辑。
- **AI 可靠性层**：所有 AI 调用统一经过 `generateGuarded`——输入清洗（隐藏密钥 / Bearer 令牌 / 「密码：xxx」字样、去控制字符、限长）；输出容错（去代码围栏、截取 JSON、修尾随逗号）；解析不合规时把错误反馈给模型自动纠正重试一次，网络 / 超时 / 5xx 也自动重试一次，鉴权类错误不重试。
- **插件后台**（工具栏弹窗 → 「插件后台」，或扩展详情页 → 扩展程序选项）：**AI 对话记录**（每次请求的提示词、返回、模型、耗时、用途、是否重试，可搜索 / 筛选，下载 JSON 或 Markdown，用于调优提示词）、**操作记录**、**页面自检**。记录只存本机，不含 API Key，最多保留 150 条 AI 记录 / 100 条操作记录。
- **撤销**：每次点「应用」前保存工单快照并记录改动；AI 栏底部出现「撤销上次应用」，可恢复标题、描述和被翻译改写的任务文字。新增的任务、负责人、日期、已发送的评论无法自动撤销（Fabriq 删除任务需要真实鼠标点击），会在确认框和后台里列出原值，便于手动还原。
- **页面自检**：AI 栏右上角「自检」对照选择器表检查当前 Fabriq 页面，指出缺失的关键元素会影响哪项功能；结果同步到插件后台。
- **安全**：AI Key 改为 AES-GCM 加密存储（密钥为不可导出的 CryptoKey，存在后台 IndexedDB），旧版明文 Key 首次使用时自动迁移；弹窗不再回显 Key，留空保存表示沿用；刷新模型列表时已保存的 Key 只会发往原接口地址。注意：Windchill / EHR 登录密码仍以明文保存在 `chrome.storage.local`（登录脚本运行在网页环境中需要读取，改动涉及各站点登录流程，需另行逐站点验证）。

## v1.5.0 (2024-03-03)

### 🔒 安全增强
- **账号密码填充重试机制**
  - 找到输入框后尝试填充3次，每次间隔0.5秒
  - 每次填充后验证是否成功（检查输入框的值）
  - 3次都失败后弹出错误提示，停止自动填充
  - 防止因页面脚本干扰导致填充失败

### 🎯 优化改进
- **更智能的填充验证**
  - 填充后等待100ms验证结果
  - 确保账号密码真正填入输入框
  - 提供详细的日志记录，方便调试

### 📢 用户提示
- 填充失败时显示友好的错误提示
- 未配置账号密码时显示警告提示
- 引导用户手动处理或检查配置
