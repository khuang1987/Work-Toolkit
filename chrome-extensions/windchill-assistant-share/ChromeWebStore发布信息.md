# Windchill Work Assistant

以下内容可直接用于 Chrome Web Store 的未列出发布。发布页面不使用公司名称。

## 基本信息

- 名称：Windchill Work Assistant
- 简短说明：Windchill 自动填充、原生搜索、文件筛选与审批摘要助手
- 分类建议：生产力工具
- 发布可见性：未列出
- 目标用户：获得安装链接的指定同事

## 详细说明

Windchill Work Assistant 是面向企业 Windchill 用户的轻量工作助手，提供以下功能：

- 登录页面账号密码自动填充，并提供“自动填充”开关。
- 使用 Windchill 原生高级搜索展示检索结果。
- 按图纸、工程文件、质量文件及 PDF、DWG、Word、Excel 等格式进行筛选。
- 在 Windchill 首页汇总当前用户的待审批任务。
- 在审批详情页顶部显示主题、编号、版本、流程、负责人、截止时间和变更说明等审批重点。
- 支持从审批摘要直接打开审批任务或主题对象。

助手只在当前 Windchill 页面权限范围内工作，不提供批量下载，不绕过访问控制。

## 隐私说明草稿

本扩展仅为实现 Windchill 检索、审批摘要和登录填充而运行。扩展读取当前 Windchill 页面内容，并使用当前浏览器登录态访问 Windchill 原生页面及只读接口。用户填写的 Windchill 用户名和密码保存在用户本机的 Chrome 扩展本地存储中，不发送给项目维护者或第三方服务器。扩展不包含广告、埋点、统计分析或远程代码加载，也不出售或共享用户数据。

用户可以随时在扩展设置中修改或停止自动填充，也可以从 Chrome 中移除扩展。扩展产生的搜索和审批结果仍受 Windchill 本身的权限控制。

## 审核测试说明

1. 安装扩展后打开企业 Windchill 首页。
2. 在扩展弹窗中填写测试账号，或使用审核人员提供的测试账号。
3. 首页右下角出现助手输入框；输入关键词并点击“检索”，Windchill 原生搜索页面会展示结果。
4. 切换到“审批”标签，首页加载待审批任务；打开任意任务后，审批页顶部显示蓝色“审批重点”区域。

审核账号、支持邮箱和隐私政策公开地址由发布者在 Chrome Web Store 后台填写，不放入扩展代码或安装包。
