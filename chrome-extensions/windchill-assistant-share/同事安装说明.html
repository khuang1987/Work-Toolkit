Windchill Work Assistant · v1.5.2

安装与使用说明

本助手用于企业 Windchill 的快速检索、文件格式筛选、待审批摘要和登录信息自动填充。

安装

  1. 打开项目维护者提供的 Chrome Web Store 链接。
  2. 点击“添加到 Chrome”，确认安装。
  3. 建议点击浏览器右上角的拼图图标，将 Windchill Work Assistant 固定到工具栏。
  4. 点击扩展图标，在“Windchill 登录”中填写自己的账号和密码并保存。
账号安全：账号密码只保存在当前电脑的 Chrome 扩展本地存储中，不会发送给项目维护者或第三方服务器。每位同事都应填写自己的账号，不要共享密码。

基本使用

  1. 打开 Windchill 首页，右下角会出现助手输入框。
  2. 输入文件号、文件名或关键词，选择图纸、工程文件、质量文件及文件格式。
  3. 点击“检索”后，结果由 Windchill 原生搜索页面展示，助手只显示结果汇总。
  4. 进入“审批”标签后，无需输入关键词；首页会读取待审批任务，打开具体任务时页面顶部会显示蓝色的“审批重点”区域。
  5. 登录页是否自动填写由“自动填充”勾选项控制；取消勾选后请手动输入。

常见问题

看不到助手？确认当前页面是企业 Windchill，并刷新页面。首次安装后建议先打开一次 Windchill 首页。

审批摘要不完整？回到 Windchill 首页等待任务列表加载完成，再进入审批详情页；详情页不会重复刷新审批列表。

想收起悬浮框？点击右上角“−”即可收起为一个 Windchill 风格图标，再次点击图标恢复。

使用范围：只在本人有权限的 Windchill 页面中使用。助手不提供批量下载功能，也不会绕过 Windchill 的访问权限。
