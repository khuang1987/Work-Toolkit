夏以昼桌面陪伴 · 1.8.1 · Windows 10/11 x64
=========================================

启动与分享
解压整个压缩包，双击 CalebDesktopPet.exe，无需安装 Python。
升级前先退出旧版，避免两个宠物同时运行。称呼、互动值和本机 AI 记录不会随压缩包分享。
这是未签名的个人同人程序。若系统提示未知发布者，请先核对来源和校验值；不要关闭系统安全防护。

操作
- 单击人物：随机动作；双击人物：摸摸。
- 按住左键拖动：移动人物，不触发摸摸。
- 右击人物：随机动作、专注、猜拳、小剧场、聊聊、隐藏夏以昼。
- 隐藏后可从系统托盘点击“显示夏以昼”恢复；托盘仍保留完整配置入口。
- 点击菜单外任意位置：自动收起菜单；Esc 收起气泡或菜单，不退出程序。
- 右击系统托盘的人物大头图标 → 配置：AI、触发键、称呼、天气、状态、提醒和动作设置。
- 右击托盘图标 → 退出：关闭程序。

沉浸式角色对话
普通聊天中，夏以昼会以第一人称、拟人化的角色口吻陪伴你，不会反复强调技术身份。问“你是谁”时会直接以夏以昼身份回答；只有明确询问程序、模型、API 或 AI 时，才会简短说明实现方式。

AI 对话
1. 右击人物 → 配置 → AI 设置。
2. 选择服务商，填写接口地址和模型；DeepSeek 默认使用 deepseek-flash，官方对应 DeepSeek-V4.1-Flash。
3. 填入你自己的 API Key，点“保存”；也可以先点“测试连接”。
4. 右击人物 → 聊聊，或单独按一下 Ctrl，输入后按 Enter 或点发送。

默认左右 Ctrl 都可触发。输入框打开后再次按触发键会切换语音热键状态；若使用微信/其他输入法，程序会向当前输入法发送一次右 Alt，实际转录行为取决于本机输入法设置。可在 AI 配置里关闭 voice_alt，或用“添加触发键”捕获被改键后的按键。

AI 回复显示在人物头顶气泡中，生成期间人物进入思考姿态。回复气泡通常 15 秒后关闭；鼠标停留时倒计时暂停，点击空白处可立即收起。只有主动发送才会调用服务，不会把桌面内容、文件或键盘文字作为上下文。

记忆与本机数据
数据目录：%APPDATA%\CalebDesktopPet\
- profile.json：称呼、互动值和基础陪伴状态。
- ai-config.json：服务商、接口、模型和 AI 功能开关。
- ai-key.bin：使用 Windows DPAPI 加密的本机 API Key。
- ai-history.jsonl：最近 30 天的完整问答记录，可在 AI 设置中导出/清空。
- ai-memory.json：从聊天中整理的长期习惯和偏好，可在设置中手动整理或重置。
- ai-reminders.json：通过聊天创建的本机提醒。

最近 12 条消息会直接用于当前对话；默认每 8 轮整理一次长期记忆，最多保留 12 条稳定信息，例如称呼、作息、工作节奏、长期项目、兴趣偏好和休息习惯。AI Key 不会写入压缩包。AI 问题和有限会话上下文只在点击发送后发给所选服务商；请勿把密码、公司机密或其他敏感信息交给外部模型。

陪伴规则
- 待机微动作有不同节奏，中间静止约 4.5–6.5 秒，动作组约 1.6–1.94 秒；自主动作低频且不会持续奔跑。
- 偶尔观察鼠标 4–8 秒；巡游、沿窗沿行走和靠边休息均有边界与间隔，可在配置中关闭。
- 100 条日常与 100 条情境原创对白，并非从游戏复制的原文。
- 喝水默认 45 分钟、休息默认 60 分钟，两类提醒至少相隔 20 分钟；可自然语言创建本机提醒。
- 亲密度会影响原创陪伴语气，但不会改变 AI 的事实边界或尊重边界。

已知限制
- 攀爬图片尚未通过动作检查，因此不启用。
- 语音按钮只负责切换当前输入法的热键，不读取、录制或上传麦克风音频；语音文字由输入法自行处理。
- AI 需要用户自己的兼容 API Key、服务商额度和网络放行；不同网关对模型名、thinking 参数和接口路径的支持可能不同。
- 本包为《恋与深空》角色同人项目，不是官方产品，不附带官方音频或游戏场景图片。
