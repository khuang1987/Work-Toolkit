# 会议纪要助手

Windows 桌面小工具:从 Outlook 读取 Teams 会议,现场一键立即开会并尝试开始转录,会议后导入 Teams 自带转写文件,用 DeepSeek AI 自动生成结构化会议纪要。

新版界面默认是窄竖版首页,只显示近期会议和核心按钮;点击会议或导入转写后才展开完整整理工作区。

> 录音与转写交给 Teams 自带功能(支持中文、免费),本工具专注"转写 -> 纪要"这一环,不需要录音和语音模型。

## 三步使用流程

1. **自动打开 Teams 并开始转录**
   填好"会议标题"后点击 `1. 自动开会并开始转录`(也可以把常开的会议"加入"链接粘贴到"会议链接"框,一键直达)。工具会用 Windows OCR 识别 Teams 的"加入/立即开会"、"更多"、"录制和转录"、"开始转录"按钮并尝试点击,识别失败时会自动发送 Teams 快捷键 `Ctrl+Shift+U`。

   如果提示自动化未完成,先在 Teams 中点一次"加入"进入会议,再回本工具点 `仅自动开始转录`;它会再次识别按钮并用快捷键兜底。

   首页的 `读取 Outlook 会议` 会读取经典 Outlook 默认日历未来 14 天的 Teams 日程。点击会议卡片上的 `打开` 会自动填入链接并执行上述流程。

   首页的 `立即开会并开始转录` 用于现场会议,不创建 Outlook 日程,会尝试打开 Teams 的 `立即开会/Meet now` 并开启转录。

2. **导入转写文件**
   会议结束后,在 Teams 聊天中打开 `录制和转录` -> `下载`,保存 `.vtt` 文件(或 `.txt`)。回到本工具点 `2. 导入转写文件` 选中它;也可以直接复制 Teams 里的转写文字,点 `粘贴转写文本`。

3. **AI 生成纪要**
   点 `3. AI 生成纪要`,等待 1-3 分钟,即可 `复制纪要` 或 `保存纪要`(自动生成 Markdown 文件,保存在"文档\会议纪要"文件夹)。

## 首次使用:配置 DeepSeek API Key

1. 打开 https://platform.deepseek.com 注册并充值(几块钱足够用很久)。
2. 在"API Keys"页面创建 Key。
3. 在本工具点 `设置`,填入 Key,点 `测试连接` 验证,保存。

## 运行方式

- **推荐**:双击 `dist\会议纪要助手.exe`(需先执行打包,见下)。
- 或直接运行源码(需 Python 3.8+、`mss` 和 `pywin32`):先执行 `pip install mss pywin32`,再双击 `run.bat`。

## 打包成 exe

双击 `build.bat`,等待完成,产物在 `dist\会议纪要助手.exe`,可拷贝到任意 Windows 电脑双击使用。

## 常见问题

- **自动化没有完成?** Teams 版本、窗口位置、语言和公司策略会影响 OCR。把 Teams 会议窗口切到前台,确认已经进入会议,再点 `仅自动开始转录`;该按钮使用按钮识别和 `Ctrl+Shift+U` 双重方式。
- **打开 Teams 按钮没反应?** 点按钮前先确认 Teams 已安装并登录过一次。失败时会自动尝试直接启动 Teams 客户端。
- **生成失败提示"API Key 无效"?** 重新生成一个 Key,注意不要有空格;余额不足会提示 402。
- **转写太长?** 工具自动截断到 30000 字,可分段多次导入并分别生成。
- **想换其他 AI?** 支持任何 OpenAI 兼容接口:在设置里改"接口地址"和"模型"即可(例如 Ollama: `http://localhost:11434/v1`)。

## 隐私

转写文本仅在生成纪要时发送给 DeepSeek API,OCR 截图只保存在系统临时目录并在识别后立即删除,其余(文件、配置、纪要)全部保存在本地。
