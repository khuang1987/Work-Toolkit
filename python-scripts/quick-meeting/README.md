# 一键开会 (Quick Meeting)

不打开任何界面，直接加入本年度固定的 Teams 会议「快捷会议纪要YYYY」（如 `快捷会议纪要2026`）并开始文字记录（转录）。一年内所有一键会议的聊天和转录都集中在同一个会议对话中。进度显示在屏幕右下角的小提示框，点击可关闭。

## 运行

- 工作工具箱 → 办公效率 → `一键开会`
- 或双击 `run.bat`（优先使用仓库根目录 `.venv\Scripts\pythonw.exe`）

依赖：`comtypes`（已装在根目录 `.venv`）。只支持新版 Teams（Windows）。

## 流程

1. 读取 `%APPDATA%\MeetingNotes\quick-meeting.json` 中当年的加入链接，用 `msteams:` 协议直接打开 → “立即加入” → 确认转录（约 6 秒）。
2. 当年首次使用且没有链接时：在 Teams 日历里逐周翻到年底，查找「快捷会议纪要YYYY」并读取加入链接后保存。
3. 日历中确实没有时，自动新建：12 月 31 日 22:00–22:30 的单次会议，设置“自动录制和听录 = 仅转录”、口述语言“简体中文(中国)”。会议可提前加入，全年可用；单次会议的链接在会议时间后 60 天才过期（“立即开会”的链接创建 60 天后就会过期，所以不用它）。
4. 只有日历完整翻到年底仍未找到才会新建，避免重复创建；任何环节失败时，退回旧流程：“立即开会”→ 会议名改为 `日期 时间` → 加入 → “更多 / 录制和转录 / 开始文字记录”。

- 通过 Windows UI Automation 直接调用按钮，Teams 窗口被遮挡也能操作。
- 已经在会议中时，直接开启转录；同一时间只运行一个实例。
- 新版 Teams 的 `Ctrl+Shift+U` 是“关闭扬声器”，因此不使用快捷键兜底。
- 想换用其他会议：删除 `quick-meeting.json` 中对应年份，或填入新的 `join_url`（`https://teams.microsoft.com/l/meetup-join/...`）。
- 运行日志：`%APPDATA%\MeetingNotes\quick-meeting.log`。

会后在 Teams 会议聊天中查看或下载转录。
